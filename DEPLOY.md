# Putting Messenger AI online (free)

| Part | Host | Cost |
|---|---|---|
| MySQL database | **Aiven** (free plan) | $0 |
| Backend (`backend/`) | **Render** (free web service, from `render.yaml`) | $0 (sleeps after 15 min idle; the first visit wakes it in ~1 min) |
| Frontend (`frontend/`) | **Vercel** (Hobby) | $0 |

Uploaded photos/voice notes are stored **in the database** online (`FILE_STORAGE=database`), because free hosts wipe
their disk on restart. Everything stays encrypted.

## 1. Database: Aiven

1. Sign up at **aiven.io** → *Create service* → **MySQL** → **Free plan** → pick a region near you → Create.
2. When it's running, open it → **Overview** → copy the **Service URI**. It looks like
   `mysql://avnadmin:PASSWORD@mysql-xxxx.aivencloud.com:12345/defaultdb?ssl-mode=REQUIRED`
3. Change the end `?ssl-mode=REQUIRED` to **`?sslaccept=accept_invalid_certs`** (both the app and Prisma's migration
   tool understand this form). This is your `DATABASE_URL`. Keep it secret.
4. (Optional, stricter) On the same page, download the **CA certificate**. Its text goes in `DATABASE_CA_CERT` so the
   app also verifies the server's identity.

## 2. Backend: Render

1. Sign up at **render.com** with GitHub → **New → Blueprint** → pick the `Messenger-Ai` repo.
2. Render reads `render.yaml`. Fill in:
   - `DATABASE_URL` = the URI from step 1.3
   - `FRONTEND_URL` = your Vercel address (step 3). Put `https://example.com` for now, then fix it after step 3.
   - `DATABASE_CA_CERT` = optional (step 1.4), or leave empty.
   `JWT_SECRET` and `MESSAGE_ENCRYPTION_KEY` are generated by Render. **Never change them later.**
3. Deploy. The first start creates all the tables (`prisma migrate deploy`). Copy the service address, e.g.
   `https://messenger-ai-backend.onrender.com`, and open it: it should say "Hello World! Chucky".

## 3. Frontend: Vercel

1. Sign up at **vercel.com** with GitHub → **Add New → Project** → import the `Messenger-Ai` repo.
2. **Root Directory**: `frontend` (Vercel asks while importing). Production branch: `main`.
3. **Environment variable**: `NEXT_PUBLIC_API_URL` = the Render address from step 2.3 (no slash at the end).
4. Deploy, then copy your site address, e.g. `https://messenger-ai.vercel.app`.

## 4. Connect them

Back in Render → the backend → **Environment** → set `FRONTEND_URL` to the Vercel address → Save (it redeploys).
That's the only website allowed to talk to the API (CORS + WebSockets).

## Good to know

- **Emails** (email/password change links) are printed in Render's **Logs** until you add `SMTP_*` settings.
- **Sparky** runs in free simple mode. Adding `ANTHROPIC_API_KEY` in Render switches on the real AI.
- **Updating**: push to `main`. Render and Vercel redeploy by themselves.
